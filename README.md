# RDBMS — One Hour Interactive Learning Session

An interactive single-page teaching dashboard for a 60-minute classroom session covering
**Unit 1** (Database Fundamentals, DBMS Architecture, Data Models, ER Model) and
**Unit 2** (Distributed Databases, RDBMS, Relational Algebra, Anomalies, Normalization).

Built with **React + Vite + Tailwind CSS**.

## Features

- **Hero + Session Roadmap** — visual 10-step roadmap of the hour
- **Section A** — Database & DBMS Fundamentals (File System vs DBMS comparison)
- **Section B** — DBMS Architecture (interactive clickable three-schema diagram)
- **Section C** — Database Models (hierarchical / network / relational)
- **Section D** — ER Model & Database Design (entities, attributes, cardinality, keys, ER diagram)
- **Section E** — Distributed Databases (fragmentation, replication, architectures)
- **Section F** — RDBMS (key elements, integrity constraints, ACID properties)
- **Section G** — Relational Algebra (interactive playground: σ π ∪ − × ⋈)
- **Section H** — Anomalies (insertion / update / deletion)
- **Section I** — Normalization (interactive stepper: Original → 1NF → 2NF → 3NF)
- **Section J** — RDBMS in One View + Quick Revision (10 q&a, key comparisons)

## Keyboard Navigation

Use **↑ / ↓** arrow keys to jump between sections while teaching.

## Getting Started

```bash
npm install
npm run dev      # start dev server
npm run build    # production build (outputs to dist/)
```
